# Test and publish a tenant skill

A tenant skill can use the JSON projection executor to select and rename values from a caller's JSON object. The executor has no access to business data, tools, or a model. A knowledge promotion can use the same executor after the knowledge receives independent review.

1. In **AI Skills**, create a tenant skill and select it in the registry. Open **Advanced manifest** and choose **Use JSON projection template**. The template extracts `/customer/name` into `name`. Edit its version and fields as needed, then create the version.
2. Open **Test draft** for that version. Save an example with the input `{"customer":{"name":"Sample Customer"}}` and expected output `{"name":"Sample Customer"}`, then select **Run all examples**. Use sample data because saved examples are visible to tenant skill administrators.
3. After every example passes, select **Review and activate**. To use the version, open **Run published skill** and enter a JSON object. Its output is generated by the same executor that ran the examples.

Examples are immutable and apply only to the version they were created for. If you need to change an example, create a new version. Built-in skills have no draft test requirement. Legacy manifests remain available in the registry and need a supported executor before they can run through the published-skill endpoint.
